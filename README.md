# [CH2] 내일배움캠프 Unreal Engine C++ 활용 프로그램 제작

# 구현 항목

## 기초 환경 설정 : 액터 세워두기
- cpp 액터 클래스 생성
- cpp 액터를 부모로 하는 블루프린트 생성
- 시작위치 0, 0, 50 고정

## 이동 및 회전 로직 구현
- AddActorWorldOffset으로 설정한 길이만큼 이동
- AddActorWorldRotation으로 설정한 각도만큼 회전
- 10회 반복

## 실시간 정보 로그 출력
- 좌표 로그 출력


## 상태 정보 실시간 출력
- 몇번째 이동인지 화면에 출력

## 50% 확률 이벤트 시스템
- 50% 확률로 실행시키는 이벤트 구현

## 최종 결과 리포트
- 전체 시스템 통합
